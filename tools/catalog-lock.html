۲. بارگذاری در GitHub

  1. هر دو فایل catalog.json و catalog.bin را از مرحله ۱ دانلود کنید.
  2. صفحه بارگذاری پوشه assets/catalog را در GitHub باز کنید:
    باز کردن صفحه بارگذاری
  3. هر دو فایل را داخل صفحه بکشید (فایل‌های قبلی جایگزین می‌شوند) و دکمه سبز Commit changes را بزنید.
  4. چند دقیقه صبر کنید تا سایت به‌روز شود؛ از آن به بعد فقط کد جدید کار می‌کند.

برای عوض کردن خود کاتالوگ هم همین مراحل را با فایل PDF جدید انجام دهید. فایل PDF اصلی را در GitHub بارگذاری نکنید، چون هر کسی می‌تواند آن را بدون کد دانلود کند.

۳. آزمایش کد روی سایت

بعد از به‌روز شدن سایت، کد را اینجا امتحان کنید تا مطمئن شوید درست کار می‌کند.
